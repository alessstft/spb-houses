# Дома Санкт-Петербурга

Дашборд по жилищному фонду Санкт-Петербурга на основе открытых данных ГИС ЖКХ
(«Сведения по ОЖФ»). Поиск домов по адресу и улице, карточка дома и выгрузка
реестра помещений в Excel по шаблону.

Сайт статический, работает на GitHub Pages без сервера и сборки.

## Структура

```
index.html                 разметка страницы
css/style.css              стили (светлая и тёмная тема, мобильная версия)
js/
  main.js                  точка входа: состояние, обработчики событий
  config.js                настройки: пути к данным, столбцы, шаблон реестра
  utils.js                 общие функции (форматирование, склонения и т.п.)
  address.js               разбор адресов и названий организаций
  file-reader.js           чтение CSV/Excel, сохранение файла в IndexedDB
  house-table.js           модель таблицы домов: поиск столбцов, фильтрация
  premises.js              загрузка помещений дома из data/premises
  registry-export.js       выгрузка реестра помещений в Excel
  ui/
    house-list.js          список домов
    house-card.js          карточка дома
    notify.js              статус и всплывающие сообщения
scripts/
  prepare.sh               подготовка данных для сайта
  houses.awk               свод выгрузки по домам
  premises.awk             раскладка помещений по файлам
  status.awk               колонка СТАТУС для полной выгрузки
data/                      сюда попадают подготовленные данные
```

## Статусы помещений

| Статус | Правило |
|--------|---------|
| МКД | тип помещения пустой (строка самого дома) |
| КВ | жилое, есть кадастровый номер |
| НЖ | нежилое, есть кадастровый номер |
| ОИ | нежилое, нет кадастрового номера |
| ЧКВ | жилое, нет кадастрового номера, есть номер комнаты |

## Подготовка данных

1. Скачать архив «Сведения по ОЖФ» с dom.gosuslugi.ru и достать из него файлы по городу:

   ```bash
   tar -xzvf Сведения*.tar.gz --wildcards "*Петербург*"
   ```

2. Из папки проекта запустить (путь — папка, где лежат CSV):

   ```bash
   bash scripts/prepare.sh ..
   ```

   Появятся `data/spb_houses.csv` (список домов) и `data/premises/p_*.csv` (помещения).

## Локальный запуск

Страница использует ES-модули, поэтому открывать её нужно через локальный сервер,
а не двойным кликом по файлу:

```bash
python3 -m http.server 8000
```

и затем http://localhost:8000.

## Публикация

Загрузить содержимое папки в репозиторий, включить GitHub Pages
(Settings → Pages → Deploy from a branch → main, / (root)).
